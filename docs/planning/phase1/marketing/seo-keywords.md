  "@type": "LocalBusiness",

## On-Page SEO Checklist

For every page:

- [ ] Title tag: 50–60 characters, keyword first
- [ ] Meta description: 150–160 characters, includes CTA
- [ ] One H1 per page, includes primary keyword
- [ ] URL slug: short, keyword-rich, hyphenated
- [ ] Image alt text: descriptive, includes keyword where natural
- [ ] Internal links: 2–3 per post, link to related content
- [ ] Schema markup: Article, Organization, LocalBusiness
- [ ] Page speed: <3s load time
- [ ] Mobile responsive
- [ ] Open Graph tags for social sharing
