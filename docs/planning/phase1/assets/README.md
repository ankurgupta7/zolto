# Kalakosh Photo Assets

Real Kalakosh photography, provided by the founder, resized for repo use
(max 1800px edge, JPEG q85 except the composite graphic). Originals were
63.5MB across 25 unique images (deduped from 3 overlapping batches); these
copies total ~6.5MB.

**Disclosure:** every image in this folder except `raw-originals/` is
AI-restyled — the product is real, everything else (backdrop, styling, and
any model or scene) is AI-generated. See
`phase1/marketing/ai-photography-pitch.md` for the pitch this supports and
`phase1/legal/pilot-agreement-simple.md` for the disclosure Kalakosh agreed
to. **Do not publish any of these publicly until that agreement is signed**
(see the "Content release IS required" note at the top of `phase1/tracker.md`).

## Folders

- `necklaces/` — clean flat-lay shots (marble + rose petal), some still
  showing a retail tag/thread (files marked `-with-tag`) that would need
  cropping before use.
- `earrings/` — clean flat-lay shots.
- `bracelets-and-mixed/` — one multi-item flat-lay (bangle + two earring
  pairs in a single frame) — good photo, not a single-SKU shot.
- `lifestyle/` — AI-generated model/scene shots showing pieces worn. Best
  suited to hero/about/story imagery rather than single-product listings,
  since most show multiple pieces at once.
- `storefront/` — the one shot set outside the actual Kalakosh Zurich
  shopfront signage; strongest candidate for the About/Story page.
- `raw-originals/` — the one genuine, unstyled phone photo in the dump
  (earrings on a car/concrete surface, harsh light). This is the "before"
  half of the before/after pair referenced in the AI-photography pitch.
- `marketing-graphics/` — a pre-composed graphic with baked-in text
  ("The Pearl Edit"); usable for social, not as a raw product photo.
